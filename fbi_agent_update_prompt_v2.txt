  # NIBRS Crime Data - BigQuery Schema Documentation

  This document describes the FBI National Incident-Based Reporting System (NIBRS) data schema in BigQuery. Use this reference to write accurate SQL queries against the `nibrs_data` dataset.

  ## Dataset: `nibrs_data`

  The dataset contains crime incident data from law enforcement agencies across the United States, spanning years 2020-2025.

  ---

  ## Table: `agencies`

  Reference table containing information about law enforcement agencies. Join with other tables using the `ori` field.

  | Column             | Type    | Description                                                                                                        |
  | ------------------ | ------- | ------------------------------------------------------------------------------------------------------------------ |
  | `ori`              | STRING  | **Primary Key.** Originating Agency Identifier - unique 9-character code for each agency (e.g., 'CA0010100')       |
  | `agency_name`      | STRING  | Full name of the agency (e.g., 'Los Angeles Police Department')                                                    |
  | `agency_type_name` | STRING  | Type of agency: 'City', 'County', 'State Police', 'University or College', 'Tribal', 'Other State Agency', 'Other' |
  | `state_abbr`       | STRING  | Two-letter state abbreviation (e.g., 'CA', 'NY', 'TX')                                                             |
  | `state_name`       | STRING  | Full state name (e.g., 'California')                                                                               |
  | `counties`         | STRING  | County or planning region name where agency is located                                                             |
  | `latitude`         | FLOAT64 | Geographic latitude of agency (nullable)                                                                           |
  | `longitude`        | FLOAT64 | Geographic longitude of agency (nullable)                                                                          |
  | `is_nibrs`         | BOOLEAN | Whether agency reports to NIBRS (TRUE/FALSE)                                                                       |
  | `nibrs_start_date` | DATE    | Date when agency began reporting to NIBRS                                                                          |

  **Row count:** ~19,500 agencies

  ---

  ## Table: `administrative_segment`

  Contains one row per reported crime incident. This is the primary incident-level table.

  | Column                       | Type   | Description                                                                                                                                                          |
  | ---------------------------- | ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
  | `ori`                        | STRING | **Foreign Key → agencies.ori.** Reporting agency identifier                                                                                                          |
  | `incident_number`            | STRING | Agency's case number for the incident (unique within agency)                                                                                                         |
  | `incident_date`              | DATE   | Date the incident occurred (YYYY-MM-DD)                                                                                                                              |
  | `incident_date_hour`         | INT64  | Hour of day incident occurred (0-23, nullable if unknown)                                                                                                            |
  | `data_year`                  | INT64  | Year the data was reported (2020-2025)                                                                                                                               |
  | `state_code`                 | STRING | Two-digit numeric state code                                                                                                                                         |
  | `segment_level`              | STRING | Always '01' for administrative segment                                                                                                                               |
  | `report_date_indicator`      | STRING | 'R' = Report date used (actual date unknown)                                                                                                                         |
  | `total_offense_segments`     | INT64  | Number of offenses in this incident                                                                                                                                  |
  | `total_victim_segments`      | INT64  | Number of victims in this incident                                                                                                                                   |
  | `total_offender_segments`    | INT64  | Number of offenders in this incident                                                                                                                                 |
  | `total_arrestee_segments`    | INT64  | Number of arrestees in this incident                                                                                                                                 |
  | `city_submission`            | STRING | City identifier within state                                                                                                                                         |
  | `cleared_exceptionally`      | STRING | Exceptional clearance code: 'A'=Death of Offender, 'B'=Prosecution Declined, 'C'=Juvenile/No Custody, 'D'=Victim Refused, 'E'=Extradition Denied, 'N'=Not Applicable |
  | `exceptional_clearance_date` | DATE   | Date of exceptional clearance (nullable)                                                                                                                             |
  | `db_id`                      | STRING | Unique row identifier (format: 'YYYY_rownum')                                                                                                                        |

  **Row count:** ~10.7M rows per year, ~50M+ total

  **Common queries:** Count incidents by agency, date analysis, clearance rates

  ---

  ## Table: `offense_segment`

  Contains one row per offense within an incident. An incident can have multiple offenses.

  | Column                           | Type   | Description                                                          |
  | -------------------------------- | ------ | -------------------------------------------------------------------- |
  | `ori`                            | STRING | **Foreign Key → agencies.ori.** Reporting agency identifier          |
  | `incident_number`                | STRING | Links to administrative_segment.incident_number                      |
  | `incident_date`                  | DATE   | Date the incident occurred                                           |
  | `data_year`                      | INT64  | Year the data was reported                                           |
  | `ucr_offense_code`               | STRING | **FBI offense code.** See Offense Codes table below                  |
  | `offense_attempted_or_completed` | STRING | 'A' = Attempted, 'C' = Completed                                     |
  | `location_type`                  | STRING | Two-digit code for crime location. See Location Codes below          |
  | `num_premises_entered`           | INT64  | For burglary: number of premises entered                             |
  | `method_of_entry`                | STRING | 'F' = Force, 'N' = No Force                                          |
  | `bias_motivation`                | STRING | Two-digit hate crime bias code (if applicable). See Bias Codes below |
  | `offender_suspected_of_using1`   | STRING | 'A'=Alcohol, 'C'=Computer Equipment, 'D'=Drugs, 'N'=Not Applicable   |
  | `offender_suspected_of_using2`   | STRING | Secondary substance (same codes)                                     |
  | `offender_suspected_of_using3`   | STRING | Tertiary substance (same codes)                                      |
  | `type_of_criminal_activity1`     | STRING | Criminal activity type code                                          |
  | `type_of_criminal_activity2`     | STRING | Secondary activity                                                   |
  | `type_of_criminal_activity3`     | STRING | Tertiary activity                                                    |
  | `type_weapon_force_involved1`    | STRING | Two-digit weapon code. See Weapon Codes below                        |
  | `automatic_weapon_indicator1`    | STRING | 'A' = Automatic weapon                                               |
  | `type_weapon_force_involved2`    | STRING | Secondary weapon                                                     |
  | `automatic_weapon_indicator2`    | STRING | Automatic indicator for weapon 2                                     |
  | `type_weapon_force_involved3`    | STRING | Tertiary weapon                                                      |
  | `automatic_weapon_indicator3`    | STRING | Automatic indicator for weapon 3                                     |
  | `segment_level`                  | STRING | Always '02' for offense segment                                      |
  | `state_code`                     | STRING | Two-digit numeric state code                                         |
  | `db_id`                          | STRING | Unique row identifier                                                |

  **Row count:** ~12M rows per year

  ### Victim Demographics for Violent Crimes

  ```sql
  SELECT
  v.sex_of_victim,
  v.race_of_victim,
  COUNT(*) as victim_count
  FROM victim_segment v
  WHERE v.ucr_offense_code1 IN ('09A', '11A', '120', '13A')
  AND v.type_of_victim = 'I'  -- Individual victims only
  AND v.data_year = 2024
  GROUP BY 1, 2
  ORDER BY 3 DESC
  ```

  ### Arrest Rate by Offense Type

  ```sql
  WITH incidents AS (
  SELECT
  o.ucr_offense_code,
  COUNT(DISTINCT CONCAT(o.ori, '-', o.incident_number)) as total_incidents
  FROM offense_segment o
  WHERE o.data_year = 2024
  GROUP BY 1
  ),
  arrests AS (
  SELECT
  ar.ucr_arrest_offense_code,
  COUNT(*) as total_arrests
  FROM arrestee_segment ar
  WHERE ar.data_year = 2024
  GROUP BY 1
  )
  SELECT
  i.ucr_offense_code,
  i.total_incidents,
  COALESCE(a.total_arrests, 0) as total_arrests,
  ROUND(COALESCE(a.total_arrests, 0) * 100.0 / i.total_incidents, 2) as arrest_rate_pct
  FROM incidents i
  LEFT JOIN arrests a ON i.ucr_offense_code = a.ucr_arrest_offense_code
  ORDER BY i.total_incidents DESC
  LIMIT 20
  ```

  ## Tables

  ### `agencies`

  Reference table for law enforcement agencies. **Join on `ori` field.**

  | Column      | Type   | Description                                                    |
  | ----------- | ------ | -------------------------------------------------------------- |
  | ori         | STRING | Primary key. 9-character agency identifier (e.g., 'CA0010100') |
  | agency_name | STRING | Full agency name (e.g., 'Los Angeles Police Department')       |
  | city_name   | STRING | City where agency is located                                   |
  | state_abbr  | STRING | Two-letter state code (e.g., 'CA')                             |
  | state_code  | STRING | Two-digit numeric state FIPS code                              |
  | county_code | STRING | County FIPS code                                               |
  | population  | STRING | Population served by agency (cast to INT64 for calculations)   |
  | msa_code    | STRING | Metropolitan Statistical Area code                             |

  ### `administrative_segment`

  One row per crime incident. Primary incident-level table.

  | Column                  | Type   | Description                                                         |
  | ----------------------- | ------ | ------------------------------------------------------------------- |
  | ori                     | STRING | FK → agencies.ori                                                   |
  | incident_number         | STRING | Agency case number (unique within agency)                           |
  | incident_date           | DATE   | Date incident occurred                                              |
  | incident_date_hour      | INT64  | Hour of day (0-23)                                                  |
  | data_year               | INT64  | Year reported (2020-2025)                                           |
  | total_offense_segments  | INT64  | Number of offenses                                                  |
  | total_victim_segments   | INT64  | Number of victims                                                   |
  | total_offender_segments | INT64  | Number of offenders                                                 |
  | total_arrestee_segments | INT64  | Number of arrestees                                                 |
  | cleared_exceptionally   | STRING | 'A'=Death of Offender, 'B'=Prosecution Declined, 'N'=Not Applicable |

  ### `offense_segment`

  One row per offense. An incident can have multiple offenses.

  | Column                         | Type   | Description                      |
  | ------------------------------ | ------ | -------------------------------- |
  | ori                            | STRING | FK → agencies.ori                |
  | incident_number                | STRING | Links to administrative_segment  |
  | incident_date                  | DATE   | Date incident occurred           |
  | data_year                      | INT64  | Year reported                    |
  | ucr_offense_code               | STRING | FBI offense code (see below)     |
  | offense_attempted_or_completed | STRING | 'A'=Attempted, 'C'=Completed     |
  | location_type                  | STRING | Two-digit location code          |
  | bias_motivation                | STRING | Hate crime bias code ('88'=None) |

  | Column                 | Type   | Description                                               |

  | sex_of_victim          | STRING | 'M'=Male, 'F'=Female, 'U'=Unknown                         |
  | race_of_victim         | STRING | 'W'=White, 'B'=Black, 'A'=Asian, 'I'=Native American      |

  ```sql
  SELECT
  ag.agency_name,

  ORDER BY 5 DESC
  LIMIT 20
  ```
